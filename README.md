## 🎯 核心設計目標與四大素養維度

對標經合組織 **OECD PISA 2029** 全球素養評估體系（初一生源為 2029 年參測關鍵主力）：
1. **代數抽象與建模 (Algebraic Modeling)**：從有理數、整式、一元一次方程、二元方程組到不等式組，打破算術逆向思維，建立嚴密的代數求解與運籌最佳化。
2. **空間推理與幾何論證 (Geometric Reasoning)**：幾何圖形、平行線與垂線嚴密因果證明、平面直角坐標系與向量平移、無人機/小巴軌跡避障。
3. **CER 學術論證與反駁 (CER Argumentation)**：每課貫徹 **Claim（亮主張）· Evidence（擺證據）· Reasoning（說道理）· Rebuttal（破迷思）**，直擊直覺思考盲區。
4. **MAIL 媒體與AI素養 & LDW 計算思維**：大數據數量級審查、商業促銷歧義消除、1936 美國大選民調翻車抽樣偏差剖析、西江鹹潮監測氣候素養。

## 🛠️ 30 週互動實驗室操作特色
- **可操作滑桿 (Sliders)**：動態調節基準量、公差、匯率、速度、進位權重、視角與權重。
- **動態平移與向量拖動 (Translation / Dragging)**：數軸列車位移、葡式碎石路波浪紋平移、GPS 三圓交會坐標定位。
- **幾何旋轉 (Rotation)**：足球射門視角極值旋轉、潛望鏡雙 45° 平行光學反射。
- **要素添加與實時模擬 (Adding / Toggling)**：二進制位元開關、物理天平配平、隨機抽樣分佈直方圖、壓鹹補淡流量模擬。
- **原生 OMML 數學公式一鍵複製**：支援在網頁上直接一鍵複製 Office Math Markup Language (OMML) XML，於 Word 中粘貼即為原生可編輯方程式。
- **動態實驗數據觀測表**：支援課堂即時記錄多組實驗參數，匯出學生專屬觀測紀錄。
